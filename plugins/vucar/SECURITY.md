# Security

Do not report suspected vulnerabilities, credentials, personal data, or exploit details in a public issue.

For the official public repository, use GitHub private vulnerability reporting from its **Security** tab. If that private channel is unavailable, use [Vucar's contact page](https://vucar.vn/contact) only to request a private security channel; do not place sensitive details in the initial form.

Never test the public MCP service with real personal information or traffic that could affect availability.
