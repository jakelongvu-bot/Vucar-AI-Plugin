# Support

## Usage and compatibility

Search existing issues, then open a new issue at <https://github.com/VucarVN/vucar-agent-plugins/issues> with:

- The client and version, such as Codex or Claude Code.
- The plugin version.
- The command or tool name involved.
- Expected and actual behavior.
- A minimal reproduction using synthetic vehicle data.

Remove tokens, personal information, machine-specific paths, and unrelated logs before posting.

For account, policy, or non-plugin customer support, use [Vucar's contact page](https://vucar.vn/contact) instead of this repository.

## Valuation feedback

An indicative estimate can differ from a market transaction or professional appraisal. When reporting a suspected model-quality issue, share only non-sensitive vehicle attributes and the approximate result. Do not share owner identity, contact details, registration documents, license plates, or vehicle-identification numbers.

## Security

Do not file security issues publicly. Follow [SECURITY.md](SECURITY.md).
